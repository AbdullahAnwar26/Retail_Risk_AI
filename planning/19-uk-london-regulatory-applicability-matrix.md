**Status:** Planning / research artefact. **Retrieval date for all sources: 2026-11-10.** UK data-protection law changed substantially in 2025-2026 (Data (Use and Access) Act 2025) and several FCA workstreams are still open. Items are flagged as such.
**Scope:** Retail Banking AI Intelligence subsystem (customer intelligence from transaction data, segmentation, financial needs, churn, personalised product recommendations, retention insights, protected under-18 journey). It does not make credit decisions. Credit appears only as `CREDIT_REFERRAL`, and every output carries `not_for_credit_decisioning` (DEC-42). The LLM only words explanations (see `02-retail-subsystem-scope.md`, `08-security-privacy-compliance-requirements.md`).
**Deployment track:** Track A (conventional bank) = New York City (file 13) + London, United Kingdom (this file). Track B (Islamic bank) is separate and is **not** covered here.
**Data:** Synthetic only. Most obligations below start when real customer data or real customer-facing outputs are introduced.
**File provenance:** Created 2026-11-10 at the developer's request as a companion to file 13. `AGENTS.md` treats `planning/` as read-only except appends to file 00 §5B; the creation of this file should be recorded in file 00 §5B and its change log, and ratified by the manager. [MANAGER]

## 1. Purpose, disclaimer and method

### 1.1 Purpose
- Identify which UK laws, regulations and supervisory materials **may** apply to the subsystem when deployed for a bank's London / UK retail business.
- State the condition that decides each one (above all, the bank's UK authorisation type).
- Turn each into **technical design requirements** mapped to the file 14 control catalogue (`CTL-*`), so the controls exist whatever legal concludes.
- Produce a precise question list (UQ1..) for the bank's UK legal and compliance teams.

### 1.2 Disclaimer
> **This is technical planning, NOT legal advice.** Every statement about what a UK law requires, whom it covers, or whether it applies is an interpretation that **requires confirmation by the bank's legal and compliance teams** [LEGAL-CONFIRM]. [VERIFIED-SOURCE] only means the source text was read, not that the reading is correct or complete. The bank's **UK authorisation, permissions, legal-entity structure (subsidiary vs branch), SM&CR category, products and size are UNKNOWN**. Every applicability call is therefore **conditional**. "Likely / Possible / Unlikely / Unknown" is a planning estimate for prioritising design work. No row states that a law applies.

### 1.3 Method and labels
Labels and classes are the same as file 13 §1.3.

| Label | Meaning |
|---|---|
| **[VERIFIED-SOURCE]** | The official text or page was opened and read during this session (2026-11-10). Only the specific points noted were checked. |
| **[PARTIAL]** | Some points were read at source; others (named in the row) were not. |
| **[UNVERIFIED]** | From memory, search-result snippets or secondary sources, or the source could not be opened. **Not to be relied on**; copied into §6. |
| **[RECENT]** | Made, amended or commenced in 2025-2026. |
| **[PENDING]** | Consultation, proposal or uncommenced provision at retrieval date. |

| Class | Meaning |
|---|---|
| **BINDING LAW** | Statute, statutory instrument, retained/assimilated law or FCA/PRA rule (an "R" provision) with legal force, if the firm is within scope. |
| **SUPERVISORY GUIDANCE** | Regulator guidance ("G" provisions, finalised guidance, supervisory statements, statutory codes). States expectations; legal effect varies (e.g., a statutory code must be taken into account). |
| **RECOMMENDED CONTROL** | A design or policy choice proposed by this planning work. Not required by the cited source. |
| **UNRESOLVED APPLICABILITY** | Source text known, but whether or how it reaches this bank or activity is open. |

Source notes:
- **legislation.gov.uk** (official) was read for UK GDPR articles, DPA 2018, PECR, the Equality Act 2010, FSMA 2000 s.21 and commencement SI 2026/82. Each page states that it is "up to date with changes known to be in force on or before 10 November 2026" or lists outstanding effects; legislation.gov.uk itself warns revised text may lag.
- **FCA Handbook (handbook.fca.org.uk) could not be read**: it is a JavaScript single-page app and returned only a shell. PRIN 2A text was read instead in the **made instrument inside PS22/9** (FCA 2022/31, July 2022), downloaded from fca.org.uk and extracted as text. That is the rule **as made**, not the current consolidated Handbook. CONC, BCOBS, COBS, SYSC and SUP text was **not** read.
- **ico.org.uk returned HTTP 403** to every fetch (bot protection), including the Children's code, AI guidance and DUAA pages. ICO points are therefore [PARTIAL] or [UNVERIFIED]. Note the ICO's functions transferred to the **Information Commission** on 30 Sep 2026 (verified on gov.uk; see U08); guidance below still uses the ICO name.
- **bankofengland.co.uk** (PRA) pages were read, and the current SS1/23 PDF (April 2026 version, LIAF01/26 app. 5) was downloaded and read as extracted text.
- equalityhumanrights.com was not opened; Equality Act text was read on legislation.gov.uk.
